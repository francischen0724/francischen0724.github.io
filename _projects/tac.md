TAC couples active target acquisition with source-data selection. The key idea is to use queried target labels as reliability anchors for constructing compact, target-aligned source subsets.

The project focuses on annotation-efficient cross-domain medical image segmentation under limited target labels, where the learner must decide both which target examples to label and which source examples should remain in the training set.

**Role:** First-author research project at USC.

**Stack:** PyTorch, MONAI, active-learning baselines, source-target split construction, multi-budget training, metric aggregation, and ablation pipelines.
